EmailJS 설정 안내서

야호샘의 문의 접수·자동회신을 EmailJS 대시보드에 연결하는 절차입니다. 각 단계에서 붙여넣을 값과 화면에서 누를 위치를 나누어 안내합니다.

STEP 1 · 계정 · 서비스 연결

붙여넣을 값

Gmail

화면에서 누를 위치: EmailJS 대시보드 로그인 → Email Services → Add New Service → Gmail 선택 → Google 계정 연결 및 권한 승인 → Create Service.

생성된 서비스 설정 화면의 Service ID가 아래 값과 같은지 확인합니다.

service_4v5v7dd
STEP 2 · 접수 알림 템플릿

붙여넣을 값

[문의] {{inquiry_type}} - {{from_name}}
yahogee41@gmail.com
{{from_name}}
{{from_email}}
yahogee@naver.com

화면에서 누를 위치: Email Templates → Create New Template → Settings에서 To는 yahogee41@gmail.com, From Name은 {{from_name}}, Reply To는 {{from_email}}, Subject는 [문의] {{inquiry_type}} - {{from_name}}, Bcc는 yahogee@naver.com을 입력합니다. Content 편집기 우측 상단의 코드 보기(< >)를 누른 뒤 아래 HTML 전체를 붙여넣습니다.

알림용 HTML 전체 보기 · 복사 버튼은 원본 HTML을 복사합니다
이 템플릿이 쓰는 변수
from_name, from_email, phone, company, inquiry_type, message, to_email, reply_to, submitted_at, page_url, privacy_agreed, agreed_at


  
STEP 3 · 자동회신 템플릿
붙여넣을 값
{{from_email}}
야호샘
yahogee41@gmail.com
문의해 주셔서 감사합니다 - 야호샘
화면에서 누를 위치: Email Templates → Create New Template에서 새 템플릿을 만든 뒤 To는 {{from_email}}, From Name은 야호샘, Reply To는 yahogee41@gmail.com, Subject는 문의해 주셔서 감사합니다 - 야호샘을 입력합니다. Content 편집기 우측 상단의 코드 보기(< >)를 누르고 아래 HTML 전체를 붙여넣습니다.
자동회신용 HTML 전체 보기 · 복사 버튼은 원본 HTML을 복사합니다


  
STEP 4 · 구글 → 네이버 자동 전달
화면에서 누를 위치: Gmail → 설정(톱니바퀴) → 모든 설정 보기 → 전달 및 POP/IMAP → 전달 주소 추가 → yahogee@naver.com 등록 → 네이버로 온 확인 메일 인증 → 전달 및 POP/IMAP에서 수신 메일 사본 전달을 켭니다.
그 다음 Gmail 검색창의 필터 옵션 → 받는 사람에 yahogee41@gmail.com 입력 → 필터 만들기 → 전달 대상을 yahogee@naver.com으로 지정합니다. EmailJS가 내 Gmail로 보내는 자기발신 메일은 전달 필터가 걸리지 않을 수 있습니다. 전달이 되지 않으면 STEP 2 알림 템플릿의 Bcc에 yahogee@naver.com을 넣는 대안을 사용합니다.


  
STEP 5 · 문의 내역 분류
화면에서 누를 위치: Gmail 검색창의 필터 옵션 → 제목에 [문의] 입력 → 필터 만들기 → 라벨 적용 → 새 라벨을 만듭니다.
  • 라벨 이름 예시: 홈페이지 문의
  • 보관 여부: 받은편지함을 건너뛰지 않으면 새 문의를 즉시 확인할 수 있습니다.
  • 답변을 마친 문의를 자동 보관하려면 후속 필터에서 받은편지함 건너뛰기를 선택합니다.


  
STEP 6 · 동작 테스트
화면에서 누를 위치: 실제 홈페이지 문의 폼에서 테스트 정보를 입력하고 개인정보 동의 → 문의 보내기를 누릅니다.
  • yahogee41@gmail.com에 접수 알림이 도착하는지 확인합니다.
  • 입력한 문의자 이메일에 자동회신이 도착하는지 확인합니다.
  • yahogee@naver.com으로 전달되는지 확인합니다.
  • Gmail에 홈페이지 문의 라벨이 자동으로 붙는지 확인합니다.
